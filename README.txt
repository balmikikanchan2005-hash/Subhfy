subhfy Android starter project

This is a starter Android Studio project (source code), not a compiled APK.
It currently includes the black/purple home screen, language chips, sample song rows,
favourite toggles, and a demo player control. It does not stream real music yet.

To build an APK:
1. Open this project in Android Studio.
2. Let Gradle sync (Android Gradle Plugin 8.6.1; compile SDK 35).
3. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Android Studio will show the generated APK location.

Use only music you own or are licensed to distribute.
